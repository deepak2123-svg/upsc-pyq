# Canonical taxonomy

`upsc-geography-v1.2.json` is the current versioned PDF-aligned registry used by the
builder. Geography owns the four geography heads; Environment owns
`Environment & Ecology`.

The question-map parts contain stable subtopic IDs for the 1,017 current
Geography/Environment records whose exam, year, paper, question number and
normalized source text matched the migration database. The remaining records
are intentionally unmapped and stay eligible only when the builder is set to
`All subsections` until an editor assigns a canonical node.
Physical Geography in v1.2 follows chapters 1–11 of the supplied outline. Its
92 canonical subparts carry explicit display order metadata; only populated
subparts are emitted by the practice inventory. The reviewed one-primary-home
migration is stored in `physical-geography-v1.2-review.json`.

`upsc-geography-v1.1.json` and the split question maps remain immutable
compatibility sources for historical recipes.
